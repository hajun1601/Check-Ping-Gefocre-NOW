Cài đặt & Server tùy chỉnh

Cách thêm server: nhập Zone ID như NP-TYO-02 (tool sẽ tự thêm .cloudmatchbeta.nvidiagrid.net) hoặc dán hostname đầy đủ, có thể thêm nhãn khu vực, rồi bấm Thêm server. Server mới sẽ hiện với thẻ “Tùy chỉnh”.

Ping được đo bằng request HTTPS tới endpoint CloudMatch của mỗi zone (request đầu bị bỏ để warm-up). Kết quả gần với ping ICMP thực tế. Server chặn request sẽ hiện “Không kết nối được”. Dữ liệu được lưu trong trình duyệt.
